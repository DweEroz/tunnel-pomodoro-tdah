# Tunnel : installeurs

Ce dépôt contient uniquement les installeurs de **Tunnel**, un timer de tunnels de concentration avec priorités du jour. Le code source est privé.

## Télécharger

Va dans [Releases](../../releases/latest) et prends :

- **Mac** : le fichier `.dmg`. Au premier lancement, macOS bloque l'app parce qu'elle n'est pas signée par Apple. Ouvre Réglages système → Confidentialité et sécurité, puis clique sur « Ouvrir quand même ».
- **Windows** : le fichier `.exe`. Si Windows affiche un avertissement, clique sur « Informations complémentaires », puis sur « Exécuter quand même ».

Tes tâches restent sur ton ordinateur. Rien n'est envoyé nulle part.

Les mises à jour se proposent toutes seules dans l'app.
